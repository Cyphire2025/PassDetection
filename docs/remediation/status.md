## How status is counted

- **Closed:** the bounded original defect has a source fix and relevant retained local evidence. This describes the candidate code, not deployment to the VPS. Final aggregate release gates still apply.
- **Partial:** relevant code or evidence exists, but an original acceptance requirement, current-image rerun, deployment integration or external operating proof remains outstanding. Partial findings are not counted as fixed.
- **Open:** no sufficient scoped remediation is established for the original finding. Passing nearby tests or changing related code does not close it.
- **RelatedClosed:** an additional supporting defect or unnumbered observation was fixed. These entries are disclosed separately and never added to the baseline closure count.
