# Additional findings discovered during remediation

Interim register, 27 September 2026. These **20 engineering defect groups** are separate from the original 44 finding groups. They include defects discovered in the earlier phase and problems caught in newly written remediation code before deployment. Do not add them to the original denominator or claim that they were all defects in the original production application. Scanner package/advisory matches are inventory evidence, not separate confirmed application exploits.

Current grouping: **six High, five Medium and nine Low**. Severity describes the consequence if the affected path/control is used; the evidence column records actual demonstrated conditions. Local qualification does not establish production deployment. The full integrated candidate remains under test.
